# DSA-leetcode

Solutions to LeetCode problems, written while practicing for technical interviews.

Not limited to one language — new solutions get added as I work through problems, in whatever language fits.

## Structure

Solutions are organized by language:

```
DSA-leetcode/
├── python/
├── java/
└── ...
```

Each file is named `<leetcode-number>_<short-description>` and solves the problem it's numbered after.
